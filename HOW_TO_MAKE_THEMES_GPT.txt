SLEEPWELL — HOW TO MAKE A THEME
For a GPT that is writing a color pack. Follow this exactly.

WHAT YOU ARE MAKING
One HTML file in Themes/. The homepage and every machine read the JSON
inside it and repaint. The page background comes from your "scene".
The old blood-splatter background is deleted. Do not bring it back.

FILE
  Themes/YOURNAME.html

SHAPE
  <!DOCTYPE html>
  <html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>SLEEPWELL theme — Your Name</title>
    <script type="application/sleepwell-theme">
    {
      "id": "yourname",
      "name": "Your Name",
      "tag": "one sentence a person could say out loud",
      "vars": { "...": "..." },
      "scene": "css background-image layers, no url()",
      "veil": "one soft vignette"
    }
    </script>
  </head>
  <body>
    <p>Your Name theme pack for SLEEPWELL.</p>
  </body>
  </html>

THEN
Add {"file": "YOURNAME.html"} to the themes array in Themes/themes.json.
id is lowercase, no spaces. It becomes data-sw-theme.

VARS YOU MUST SET
  --bg            page color under the scene
  --panel         machine panel
  --panel-2       inset / inputs
  --accent        main color
  --accent-dim    darker accent
  --accent-bright lighter accent
  --accent2       second color
  --text          primary text
  --text-dim      secondary text
  --border        hairline
  --glow          rgba() used on the frame
  --radius        usually 0px or 2px
  --font          a single font stack

Text on --panel must be readable. Check --text against --panel, not against white.

SCENE AND VEIL
scene is the value of background-image. Layers separated by commas.
Gradients only. No url(). No animation. No blur filter. 3 to 5 layers.
veil is one radial-gradient: transparent in the middle, darker at the edge,
tinted with the theme, not a red stain.

The scene has to match the name. If someone can guess the theme from the
background alone, it is good enough.

QUALITY BAR — MATCH TRIPPAH AND GOONR
TRIPPAH
  Wine cellar. Deep plum, a pink lamp at the top-left, a faint horizontal
  scan. Motion is a few falling spores drawn by the runtime. You do not
  animate type. You do not wrap letters.

GOONR
  Black-green room, scan lines, a faint cyan grid, a green glow at the floor.
  The runtime draws the matrix rain. Your scene is the still room under it.

THE OTHER ROOMS, SO YOU DO NOT MAKE THEM ALL THE SAME RED
  Default    clean night, one soft red lamp at the top. Not splatters.
  Light      warm paper, faint ruled lines.
  Ash        cold smoke, grey streaks.
  Sulfur     sick lime haze, a little chemical red in a corner.
  Bloodmoon  ONE moon: bright core, red ring, black sky. Not drips.
  Violet     ultraviolet clouds.
  Moss       damp green from the left, a little gold at the floor.
  Amber      honey light rising from the bottom, like a sodium lamp.
  Void       near-black, one or two tiny stars. Mostly empty.
  Neon       magenta wash at the top, a cyan grid.
  Bone       ivory on charcoal, parchment lines.
  Rust       diagonal metal streaks, orange in the low corner.
  Ice        frost at the corners, pale cyan scan.
  Wine       cellar. Dark bottle shapes, one overhead lamp. No falling spores
             (that motion belongs to TRIPPAH).

PERFORMANCE — TRIPPAH USED TO BE LAGGY
Do not do any of these in a theme:
  - a span around every letter
  - a MutationObserver on the document
  - an animation on every element
  - a CSS filter on body
  - a canvas that redraws the full window every frame
  - more than a handful of moving pieces
scene and veil are static paint. That is the whole trick.

DO NOT COPY THIS
The removed splatter was a pile of small red ellipses:
  radial-gradient(ellipse 180px 120px at 8% 12%, rgba(140,10,10,.55), ...)
and a dozen more like it. That is not a theme. Delete it if you see it.

A finished theme is one HTML file plus one line in themes.json.
Open the homepage, pick the theme, and the gutter around every machine
should look like the name you wrote.
