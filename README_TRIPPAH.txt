TRIPPAH website package
=======================

VST downloads
-------------
Open index.html and use the Master / Share switch in the VST3 downloads
panel. Share downloads DownloadVSTFile/Two/DreamShareVst.zip, which contains
the DreamShare Lite VST3 bundle. Unzip it and install the
"DreamShare Lite.vst3" folder in:

  C:\Program Files\Common Files\VST3

Master downloads DownloadVSTFile/One/Master.zip and contains the
DreamMasterLite VST3 bundle. Unzip it and install the "DreamMasterLite.vst3"
folder in the same location. Then rescan plugins in your DAW.

Samples
-------
Keep the lowercase samples folder beside index.html, library.json, and
"Pluggins Folder". The drum and synth machines load audio from this folder;
library.json and the machine HTML files use lowercase samples/ paths.

When uploading the site, include the complete samples folder and preserve
its DreamDrums and DreamSynth subfolders. Do not put sample files inside
the VST download folders.

Full upload package
-------------------
TRIPPAH-Website-Upload.zip (beside the TRIPPAH folder) contains the complete
website, all HTML pages, the current samples/ folder and license, plus both
per-plugin ZIP downloads. The individual VST ZIPs are deliberately
sample-free; sample files stay at the site root for the instruments to load.
