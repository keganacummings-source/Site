SLEEPWELL — How to use
======================

Open index.html (or the hosted site). Everything lives in one package.

Home
----
Machine cards = plugins. Click to open.
Open DreamBuilder for the playlist / arrangement.
ABC button in DreamBuilder opens the full DREAMABC machine docked in the builder (not a separate embed).
In DESIGN mode, ABC opens full-screen like other machines.
Plugin Browser never lists Beta machines (Unlock Beta still works on the home grid).
DAW / DESIGN toggle:
  - DAW = full studio (DreamBuilder + plugins).
  - DESIGN = plugins only (DreamBuilder is hidden).
LEARN = hover a control for a short tip (written for beginners).
Theme / Stylist / Log In / Save Session as needed.
Unlock Beta tools to see Beta* machines.

Closing a plugin
----------------
✕ Close sends you back where you opened it from:
  - Plugin grid (home) if you picked the machine from the cards.
  - DreamBuilder if you opened it from the arrangement / track drop.
Minimize does the same, but keeps the machine running in the background.

Click vs double-click in libraries
---------------------------------
Click        = preview
Double-click = load into the machine
Folders start closed. Open only what you need.

DreamBuilder
------------
Left column: Sample Browser + Plugin Browser (both fit).
  - Samples: click to preview, drag onto a lane.
  - Plugins: drag onto a track → that track links the plugin for live FX and the plugin opens.
    Close returns to DreamBuilder so you can keep arranging.

ABC button (in DreamBuilder): opens the FULL DREAMABC machine docked in the builder. Drag a sample onto ABC to load it into the session library. In DESIGN mode it opens full-screen. Use ↗ Full in the dock bar to pop out to embed mode.

← Plugins / Back
  - ← Plugins returns to the machine grid (arrangement is kept).
  - Back returns to the last plugin or place you were.

While a plugin is open:
  - Use ← DreamBuilder (or the embed bar control) to go back to the playlist without quitting the machine.
  - Mix button can keep the arrangement playing under the open machine.

Dream mode
----------
Per-track subtle polish (space, light pan, soft lofi). Kept mild on purpose —
heavier processing belongs in the plugins you drop on tracks.

Playlist controls
-----------------
GRID / FREE per track.
Lock a track so Dream / reshuffle will not change its sample + FX recipe.
Waveforms on clips. Live volume / mute / solo / pan / fades.
Split, Dup, Clone, LOP loop region.
Export Mix = final download + session copy.
Rebalance = optional light FET-style glue + limiter for level polish
when you cannot check on headphones. Keep it off if you already mix hot.
SESSION / MIDI holds ABC (and dropped) MIDI clips. Drop a sample onto a
MIDI clip to test that sample across the written notes. Dream FX still apply.

ABC (full machine)
------------------
Pocket piano roll, SIZE, COMPLEXITY, Randomize, AUTO CUT / FULL / CHORDS, MET.
Keys Z X C V B N M play the seven naturals. Comma / period change octave.
AUTO CUT fades the previous note on a voice but keeps a chord together.
FULL off uses the roll note length. Export is trimmed to the exact loop
(no leading hole when you drop the tape onto DreamBuilder).
Save MIDI parks the roll in SESSION / MIDI. Drag that clip onto a
DreamBuilder lane, then drag a sample onto the MIDI clip to voice it.
⬇ MIDI still downloads a .mid file.

INSOMNIA
--------
Multi-bay sample rack + FX cards. Turning an FX on appends it to the
numbered chain (↑ / ↓ move the slot). RND CHAIN shuffles only the order
of FX that are already on. Playback and export share the same rack.

Adding samples or machines
--------------------------
1. Drop .wav / .mp3 into samples/SomeFolder/
2. Drop new .html into Pluggins Folder/
3. python3 update-library.py   (or Refresh catalog in GOODNIGHT)
4. Zip SLEEPWELL and upload

Optional disk folder (Chrome/Edge/Opera): can also write FinalProjects/ and
per-machine folders. Not required for session work.

VST install (Windows)
---------------------
Use the VST3 dropdown on the GOODNIGHT master HTML. Every choice downloads a
complete standalone installer EXE for that plugin.

Run the downloaded EXE. It contains its own payload, asks Windows for
Administrator permission when needed, removes duplicate copies of that plugin,
and installs one copy. No ZIP extraction is required.

The old master bundle button is no longer used by the website. The individual
installer EXEs are the supported download path.
