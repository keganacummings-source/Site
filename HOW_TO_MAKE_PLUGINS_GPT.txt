SLEEPWELL — HOW TO MAKE A PLUGIN
For a GPT that is writing a new machine. Follow this exactly.

WHAT YOU ARE MAKING
One self-contained HTML instrument. It opens inside the GOODNIGHT homepage
(an iframe) and must fill whatever window it is given. It must pick up the
active theme. It must not invent its own page background.

WHERE THE FILE GOES
  Pluggins Folder/DREAMYOURNAME.html
Do not start the name with Beta.
Do not edit other machines unless the person asked you to.

REQUIRED HEAD
  <!DOCTYPE html>
  <html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>DREAMYOURNAME</title>
    <script src="../Themes/sleepwell-theme.js"></script>
    <script src="../Themes/sleepwell-suite.js"></script>
    <style>
      /* your CSS */
    </style>
  </head>
  <body>
    <div class="app">
      ...
    </div>
  </body>
  </html>

LAYOUT — THIS IS THE PART THAT KEEPS BREAKING
1. The machine fills the window. No max-width on .app. No transform:scale.
   No --design-w. No --ui-scale. No fixed 560px stage.
2. Structure:
     .app is the only panel.
     It is width 100%, flex 1, min-height 0, overflow auto.
     The header/controls stay at the top. The work area scrolls inside .app.
3. Grids and flex rows need min-width: 0 so text can shrink instead of
   overflowing the window.
4. Words wrap on spaces only.
     overflow-wrap: break-word;
     word-break: normal;
   Never split a word into one span per letter.
5. If a view should be invisible, use the hidden attribute, or:
     .hidden { display: none !important; }
   A class of "hidden" with no CSS rule still draws. That is how DreamShare
   stacked the closed door, the floor, and the thread on top of each other.
6. At 390px wide: controls wrap, nothing scrolls sideways, buttons are at
   least 34px tall.
7. The suite already draws the DreamAxe frame (2px accent border, hard
   offset shadow that follows --sw-edge, inset accent line). Do not replace
   that with a max-width card.

COLORS
Use only the theme variables. Do not hardcode a page background.
  --bg  --panel  --panel-2
  --accent  --accent-dim  --accent-bright  --accent2
  --text  --text-dim  --border  --glow  --font  --radius
Do not set background-image on body.
Do not paint blood splatters, red drips, or a vignette of many small
red ellipses. The theme paints the page behind the panel.
Your panel background should be var(--panel) or a mix of var(--panel)
and var(--bg). Leave the body alone.

AUDIO
Use the Web Audio API. Resume the context on the first click or key.
When the person saves a tape, call:
  await dreamSaveBlob(blob, "DREAMYOURNAME_take.wav");
That parks it in the homepage session. A download-only button is not enough.
You may also use dreamNormalizeBuffer(buffer) and dreamLiveCeiling(ctx, dest).
To list package samples: await dreamRequestSamples("").

DO NOT
- Wrap letters in spans, or watch document.body with a MutationObserver.
- Steal Alt+H. sleepwell-suite.js already sends the homepage hotkey.
- Add a second login. DreamShare uses the homepage account.
- Use document.write.
- Load a giant animated canvas behind the whole UI.

CATALOG
Add one object to the plugins array in library.json:
  {
    "name": "DREAMYOURNAME",
    "fileName": "DREAMYOURNAME.html",
    "url": "Pluggins Folder/DREAMYOURNAME.html",
    "family": "Tools"
  }
family is one of: Keys, Drums, Strings, FX, Voice, Tools.

MINIMUM SKELETON
  .app { display:flex; flex-direction:column; min-height:0; background:var(--panel); color:var(--text); }
  .top { display:flex; flex-wrap:wrap; gap:6px; align-items:center; padding:8px; border-bottom:1px solid var(--border); }
  .work { flex:1; min-height:0; overflow:auto; padding:12px; }
  button { min-height:34px; background:var(--panel-2); color:var(--text); border:1px solid var(--border); }
  h1, p, button { overflow-wrap:break-word; }

A good plugin is usable the moment the window changes size. If you have to
pick a number of pixels, you picked wrong.
